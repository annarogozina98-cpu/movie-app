# Кино на двоих

Веб-приложение с тремя экранами:

1. **Хотим посмотреть** — список фильмов; название, рейтинг, ссылки на IMDb/Кинопоиск, длительность, описание, жанр, год. Данные подтягиваются автоматически при добавлении фильма.
2. **Посмотрели** — название, рейтинг, год, ваша оценка, комментарий, дата просмотра. Оценку и комментарий можно редактировать в любой момент.
3. **Рекомендации ИИ** — Claude анализирует список «Посмотрели» (особенно ваши оценки и комментарии) и предлагает новые фильмы с теми же данными; кнопки «Добавить» / «Отклонить».

Работает с телефона и компьютера, данные хранятся в общей базе (Supabase) и синхронизируются у обоих. Доступ — по скрытой ссылке, без пароля (никому её не пересылайте).

Стек: Next.js 14 + Supabase (Postgres) + Vercel + Claude API + OMDb API.

---

## Шаг 1. Supabase (база данных)

1. Зайдите на [supabase.com](https://supabase.com) → **New project**. Запомните пароль от базы (не понадобится, если не планируете подключаться напрямую).
2. Дождитесь создания проекта → слева **SQL Editor** → **New query**.
3. Откройте файл `supabase/schema.sql` из этого проекта, вставьте содержимое, нажмите **Run**. Это создаст три таблицы: `to_watch`, `watched`, `recommendations`.
4. Чтобы сразу загрузить ваши текущие списки фильмов:
   - Новый query → вставьте содержимое `supabase/seed_to_watch.sql` → Run (121 фильм).
   - Новый query → вставьте содержимое `supabase/seed_watched.sql` → Run (115 фильмов).
   - Названия добавятся без остальных данных — их подтянет кнопка «Заполнить данные» в приложении (можно нажимать по одному, или сразу попросить меня сделать скрипт для массового заполнения, если после деплоя это будет неудобно).
5. Слева **Project Settings → API**. Скопируйте:
   - `Project URL` → это `NEXT_PUBLIC_SUPABASE_URL`
   - `anon public` ключ → это `NEXT_PUBLIC_SUPABASE_ANON_KEY`

## Шаг 2. Ключи для данных о фильмах и ИИ

- **OMDb API** (данные IMDb: рейтинг, жанр, длительность, описание): [omdbapi.com/apikey.aspx](https://www.omdbapi.com/apikey.aspx) → free tier (1000 запросов/день) → ключ придёт на почту.
- **Anthropic API** (Claude — определяет фильм по названию и генерирует рекомендации): [console.anthropic.com/settings/keys](https://console.anthropic.com/settings/keys) → Create Key. На счету должен быть небольшой баланс (обогащение одного фильма стоит доли цента).

## Шаг 3. GitHub

1. Создайте новый пустой репозиторий на GitHub (например `movie-app`), без README/лицензии.
2. В терминале, в папке проекта:

```bash
cd movie-app
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/<ваш-логин>/movie-app.git
git push -u origin main
```

## Шаг 4. Vercel (деплой)

1. [vercel.com](https://vercel.com) → **Add New → Project** → выберите репозиторий `movie-app` из GitHub.
2. Framework Preset определится автоматически как Next.js — ничего менять не нужно.
3. Перед деплоем откройте **Environment Variables** и добавьте четыре переменные (из шагов 1–2):
   - `NEXT_PUBLIC_SUPABASE_URL`
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY`
   - `OMDB_API_KEY`
   - `ANTHROPIC_API_KEY`
4. **Deploy**. Через минуту-две Vercel даст ссылку вида `movie-app-xxxx.vercel.app` — это и есть ваша скрытая ссылка на приложение, откройте её с телефона и компьютера.

## Локальный запуск (необязательно)

```bash
npm install
cp .env.example .env.local   # и впишите туда реальные ключи
npm run dev
```

Откроется на `http://localhost:3000`.

## Как это устроено внутри

- При добавлении фильма (или нажатии «Заполнить данные») приложение спрашивает у Claude, какой реальный фильм имеется в виду (по русскому/неточному названию), затем запрашивает у OMDb рейтинг, жанр, длительность, описание и ссылку на IMDb. Ссылка на Кинопоиск строится как поисковая ссылка по названию (у Кинопоиска нет бесплатного API).
- Если OMDb не находит фильм (часто бывает с советскими/редкими фильмами), данные заполняет сам Claude — с пометкой «-» там, где он не уверен.
- Кнопка «Подобрать рекомендации» отправляет Claude ваш список «Посмотрели» с оценками и комментариями и просит подобрать 5 новых фильмов, которых ещё нет ни в одном из списков.
- «Отклонить» не удаляет рекомендацию безвозвратно, а прячет её из выдачи — так Claude не предложит тот же фильм повторно.

## Стоимость

Всё работает по free-tier: Supabase (бесплатный tier — до 500 МБ, более чем достаточно), Vercel (Hobby-план бесплатен для личных проектов), OMDb (1000 запросов/день бесплатно). Единственное, что тратит небольшие деньги — вызовы Anthropic API (доли цента за фильм); пополнить баланс можно на [console.anthropic.com](https://console.anthropic.com/settings/billing).
